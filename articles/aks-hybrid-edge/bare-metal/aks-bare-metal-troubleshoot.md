# Troubleshoot AKS on bare metal (preview)

Start with the guide that matches the failing part of your Azure Kubernetes Service (AKS) on bare metal deployment.

| Area | Use this guide |
| --- | --- |
| **Azure Linux deployment or lifecycle** | [Troubleshoot Azure Linux deployments](aks-bare-metal-troubleshoot-azure-linux-deployment.md). |
| **Ubuntu host, Azure Arc, CLI, or deployment** | [Troubleshoot Ubuntu deployments](aks-bare-metal-troubleshoot-ubuntu-deployment.md). |
| **Azure Arc proxy, credentials, RBAC, or kubectl** | [Troubleshoot cluster connectivity](aks-bare-metal-troubleshoot-connectivity.md). |

Before troubleshooting, identify the host operating system, and then use the corresponding guide in the table.
